# Ensign API documentation

\htmlonly Ensign \endhtmlonly is a C++ framework for dynamical low-rank and
interpolatory low-rank algorithms on multi-core CPUs and GPUs. This reference
documents the library API.

- For a conceptual guide to the data structures, operations,
  tensor networks, and utilities, see the
  [Overview of the code](https://leinkemmer.github.io/Ensign/api/).
- To see the library used in a complete example, follow the
  [tutorial](https://leinkemmer.github.io/Ensign/tutorial/).
